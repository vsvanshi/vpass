# VPass iOS

iOS companion app for VPass.

This app reads and writes full credential records in the shared iCloud Keychain group:

`X937FCYW2Y.com.varunsuryawanshi.vpass.shared`

The Mac and iOS apps use the same synchronizable Keychain service for credentials, passwords, extra fields, and TOTP secrets. Use the same Apple ID with iCloud Keychain enabled on both devices.
